# Original biome trees

MangroveTree: 404 triangles / 800 budget, stilt roots and compact tropical canopy.
AcaciaTree: 292 triangles / 800 budget, forked trunk and broad umbrella canopy.
Created with Blender MCP and Blender LPM for Island Survival; original models and
recipes are dedicated to the public domain under CC0 1.0:
https://creativecommons.org/publicdomain/zero/1.0/

Source geometry has one palette material with UVs and flat shading.
Runtime OBJ files in `../OBJ` use face palette names, Y-up coordinates and explicit
normals for the game's vertex-color renderer. Both trees can be chopped for wood.
Recipe: `scripts/build-biome-trees.py` at the repository root.
