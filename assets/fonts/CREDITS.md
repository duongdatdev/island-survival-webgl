# Cinzel font source

The repaired Cinzel 600 face is the original static weight served by Google Fonts:
https://fonts.gstatic.com/s/cinzel/v26/8vIU7ww63mVu7gtR-kwKxNvkNOjw-gjgTYo.ttf

Copyright 2020 The Cinzel Project Authors. SIL Open Font License 1.1 is retained
in OFL-Cinzel.txt, obtained from https://github.com/google/fonts/tree/main/ofl/cinzel.
The font was verified as TrueType, weight 600, before replacing a mislabeled HTML error page.
