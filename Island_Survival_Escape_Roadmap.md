# Island Survival: Escape – Development Roadmap

## Vision
A 3D survival game built with WebGL where the player is stranded on a small island. The goal is not to survive forever, but to gather resources, craft equipment, build a raft, and escape.

---

# Version 0.1 – MVP (1 Month)

## Goal
Deliver a fully playable game with a clear win condition.

### Core Features
- Small island
- Third-person character controller
- Camera follow & rotate
- Basic lighting
- Resource collection
- Simple inventory (resource counts only)
- Random floating debris spawning from the sea
- Basic crafting
- Build raft
- Escape ending

### Resources
- Wood
- Stone
- Rope (floating debris)
- Barrel (floating debris)

### Craft Recipes
- Stone Axe = Wood x2 + Stone x2
- Raft Frame = Wood x10
- Paddle = Wood x5 + Rope x2
- Raft = Frame + Paddle + Barrel x3

### Not Included
- Hunger / Thirst
- Save system
- Weather
- Day/Night
- Animals
- Enemies
- Durability
- Advanced UI

### Estimated Timeline
