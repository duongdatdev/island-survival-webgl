# Island Survival 2.0 — approved implementation contract

The user authorized implementation of the entire campaign and free-model acquisition on 2026-10-06. This document preserves the approved scope across long implementation sessions. Do not mark the goal complete until each acceptance item has authoritative evidence.

## Product

Single-player desktop browser, existing vanilla JavaScript/WebGL 2/Vite engine. Campaign target: 8–12 active hours, 5–7 sessions over several real days. One 640 × 640 m world, island radius 260–280 m; modular single-storey houses; moderate survival. Time stops while paused, hidden, or closed. Chapters are objective-driven, never locked to real-world days. Every 45–90 minutes should deliver a meaningful unlock or discovery; gathering quantities must not be the principal duration mechanism.

Story: shipwreck survivor follows records of an abandoned weather station damaged by storms. Six chapters: (1) water, shelter, fire, first journal; (2) workbench/storage and abandoned camp; (3) mine/ore/smelter/metal tools; (4) weather station, repair bench, diving equipment, island coordinates; (5) underwater wreck/coastal depot and supplies for either ending; (6) sail beyond the island or restore radio/signal tower and await rescue. Target cumulative chapter hours: 0–1, 1–2.5, 2.5–4, 4–6, 6–8, 8–12. Early discoveries count retroactively; quest rewards must be idempotent.

Eight main POIs: starting wreck beach, waterfall, abandoned camp, mine cave, weather station, offshore wreck, coastal depot, signal tower. Five land biomes: beach, grassland, forest, rocks, highlands. Seed changes terrain/decoration/positions without breaking the campaign. Main rewards are guaranteed, not random-only. Six side quests: rest camp, fishing expedition, first crop, shortcut, storm cargo, additional journals. Side rewards are optional supplies/convenience.

## Functional requirements and acceptance stories

- [x] FR-01 Assets: acquire selected free CC0 models and licences/source records; reuse existing Quaternius radio/batteries/compass/tent/raft/torches. Use Blender MCP for unavailable/unsuitable hook, smelter, smoker, fish trap, water tank, dive equipment, antenna and growth stages. Keep authoring sources out of production. Check actual GLB bounds, triangles, materials, runtime appearance, and production inclusion.
- [ ] FR-02 Persistence: asynchronous IndexedDB snapshot v2, serialized writes, transactional metadata, two recent snapshots plus pre-ending checkpoint. Autosave every 30 s and at meaningful state changes. Report failures honestly. Export/import JSON. Recover interrupted/corrupt writes without deleting valid data.
- [ ] FR-03 Compatibility: existing worlds remain Classic with generatorVersion=1 and their original terrain/rules; new worlds default Campaign. Migrate v1 only after successful write/readback, retain source. Settings/profile achievements stay compatible.
- [ ] FR-04 Containers: shared storage operations for 28-slot player inventory (20 backpack + 8 hotbar), 24/48-slot chests, station output and death bags. Atomic transfers/crafting; no loss/duplication on capacity limits. Select consenting chests within 5 m as craft sources.
- [ ] FR-05 Construction: 2 m foundation/floor/wall/door/roof grid, 90° rotations, preview/cost/validity. Reject water, steep slope, intersecting colliders and protected POIs. Parts depend on foundations; block destructive parent removal. Dismantle empty/inactive objects for floor(75% costs). Max 400 house parts + 80 functional objects. Multiple fires/chests/stations.
- [ ] FR-06 Shelter: actual overhead roof coverage, sleeping under roof without mandatory walls, beds set respawn, shelter initially available. Shared models are not destroyed by instances.
- [ ] FR-07 Progression: three tiers — stone survival; smelter/metal tools; repair/mechanical equipment. Craft schema includes tier/station/time/fuel/yield/blueprint. Recipe data explicitly enumerated and documented. Rope from fibre at tier 1, barrels craftable at tier 2; no dependence on random drifting loot.
- [ ] FR-08 Production: instantaneous hand crafting; five-job smelter/smoker queues reserve ingredients; cancel returns unfinished portion; fuel pauses when exhausted; full output pauses without loss. Save running queues and progress.
- [ ] FR-09 Survival: 30-minute campaign day, separate real play seconds from accelerated simulation time. Wood/charcoal fires lose effectiveness uncovered in rain, stop cooking/warming when out of fuel. Existing vitals/wetness/cold continue. Two crops (food 30 min, herb 20 min) pause without water; fish traps; smoked food. No offline simulation.
- [ ] FR-10 Activities: hook pulls debris up to 20 m, not animals; fish bite timing and tension minigame with three fish groups; actual swimming/diving, oxygen 45 s / 120 s equipped, surface recharge, damage when exhausted.
- [ ] FR-11 Death/difficulty: Standard respawn bed/safe start, keep hotbar/quest objects, backpack in permanent marked persisted bag; Relaxed drain/damage ×0.6 and retain items; Harsh ×1.4 and drop hotbar too. Always preserve quest objects. Destroyed bed falls back safely. Multiple death bags survive reload.
- [ ] FR-12 World: 40 m terrain chunks, three LODs, 1.25 m nearest grid; spatial collision/interaction; nearby AI, analytical remote crops/queues. Separate cave geometry/collision instead of heightfield holes; navigable underwater wreck. Map fog/discovery, compass, base and custom markers. Guaranteed reachable main POIs across 100 seeds.
- [ ] FR-13 Events/wildlife: reuse crab/seagull/boar/shark, react to new collision/POI rules; storm cargo, fish shoals and fallen-tree shortcut. Events must not destroy bases/quest objects. No new boss.
- [ ] FR-14 Endings: raft+ sail+navigation+supplies, motor optional; 8–12 min controllable ocean course with heading/rocks/repairs. Radio+coordinates+battery/wire+signal tower; 8–12 min power/tuning/weather challenge. Show missing prerequisites. Save before departure, retry from checkpoint. Both endings can complete in one world.
- [ ] FR-15 Postgame: preserve world and base, return to pre-departure state after ending, persist ending flags/achievements and permit other route.
- [ ] FR-16 UI: chapter journal, pinned objective/recipe, discovered map, crafting tiers, chest transfer controls, station queue, build mode, oxygen/tension, ending controls and summary. On continue show chapter/last progress/next goal. Verify every UI story directly in browser with available computer-use tooling.
- [ ] FR-17 Quality: Vietnamese text, familiar rustic game UI, clear controls, reduced-motion/accessibility, audio and tutorials updated. Run unit/integration tests and production build. Existing baseline is 119 passing tests.

## Delivery gates

M0 persistence/containers/events/Classic; M1 construction/base; M2 technology/production/activities; M3 large world and chapters 1–3; M4 chapters 4–5/diving/events; M5 both endings/postgame; M6 polish/balance/verification/docs. Small focused stories should attach to these gates; completion claims require matching evidence.

Tests must cover capacity transactions, cancellation/output-full, invalid construction/parent removal/roof coverage, early quest discovery/repeated reward/death quest protection, 100 seeded reachable worlds, v1 migration/corrupt saves/quota/export/import/interruption, consistent sleep and no offline drain, multiple deaths, both ending failure/retry/continue cases, direct browser interactions and asset rendering. Run 90-minute long-session test and switch worlds ten times for resource/listener retention. Record the test hardware; target 60 FPS medium and 30 FPS low. At least five first-time playtests assess median 8–12 h campaign length before claiming timing acceptance.

Out of scope for 2.0: multiplayer, mobile, voiced/dialogue NPCs, archipelago, New Game+, multi-storey structural physics, layered diseases, food spoilage, tool durability.
